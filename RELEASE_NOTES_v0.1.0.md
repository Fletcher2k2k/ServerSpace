# ServerSpace 0.1.0

First public release of ServerSpace.

## Highlights

- Portable Windows x64 storage analyzer
- Self-contained single-file executable
- No separate .NET installation required
- Local folder scanning
- UNC and mapped network drive support
- Live scan progress
- Hierarchical folder analysis
- Size bars
- Numeric sorting by folder size, file count, folder count and percentage
- Largest folders shown first by default
- Virtualized result view for large directory trees
- Filters for name, minimum size and empty folders
- Configurable visible columns
- Open folders directly in Windows Explorer
- Cancel running scans
- CSV report export
- TXT report export
- Export of partial results after cancelled scans
- About dialog with version and project information

## Supported systems

- Windows 10 x64
- Windows 11 x64
- Windows Server x64

## Notes

Network shares are accessed with the credentials of the Windows user running ServerSpace.

This release is the first stable public baseline. Additional storage and virtualization integrations are planned for future versions.

## Download

Download `ServerSpace.exe` from this release and start it directly.

No installer is required.
